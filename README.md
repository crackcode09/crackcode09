## 💡 Featured Projects

### 📊 Controlled Run Chart — Hybrid SPC Methodology
A six-component SPC monitoring system combining spec-anchored control limits, process mean calculation, Range/MR charts, histograms, and Pareto charts with operator reason codes. Built to bridge traditional SPC theory with real-world manufacturing floor usability.

### 📈 Manufacturing Analytics Dashboard (Power BI)
End-to-end Power BI solution connecting SyteLine ERP data via SQL Server — tracking OEE, defect rates, and production KPIs with star schema data modeling and native query optimization.

### 🔍 Digital Inspection System
Paperless inspection workflow integrating digital gauging with real-time data capture, reducing inspection cycle time and enabling traceability across production lines.
